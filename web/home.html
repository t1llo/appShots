Works with

One line sets up your agent

It installs the skill and the appshots command, and connects the agent to this server over MCP.

$ curl -fsS https://your-server/install.sh | APPSHOTS_TOKEN=<your token> sh -s claude

Then open Claude Code in your app's folder and type /appshots.

Then open Codex in your app's folder and type $appshots.

Then open OpenCode in your app's folder and ask it for your App Store screenshots.

Then open Pi in your app's folder and type /skill:appshots. Pi has no MCP, so the skill works through the appshots command.

Then tell your agent to read ~/.agents/skills/appshots/SKILL.md and follow it. If it has MCP, add the connection by hand.
